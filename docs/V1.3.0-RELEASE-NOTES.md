# Auto HDR Manager v1.3.0 — Smart Video HDR

Draft release notes. The local release candidate awaits final visual acceptance; no GitHub Release has been published.

## Smart Video HDR

- Automatically prepare Windows HDR before opening supported HDR10 or HLG MKV/MP4 files in VLC. HDR is confirmed and given one second to stabilize before playback starts.
- Restore the original HDR state after the controlled player exits. Games and videos share the existing HDR session engine, so closing one does not restore HDR while another still needs it.
- Keep SDR, unrecognized metadata and unsupported Dolby Vision files on the normal VLC playback path without automatically enabling HDR.
- Start in the tray for file activation, including cold starts, using the existing single-instance IPC and stable portable launcher.
- Opt in through the compact Smart Video HDR settings section. Windows Default Apps remains responsible for choosing MKV/MP4 defaults; the application never writes UserChoice.
- Include MediaInfoLib and its license notices in the Windows x64 portable executable. VLC is installed separately; no SDK or external metadata tool is required by the distribution.

## Polish and compatibility

- Show a discreet v1.3.0 label using the application version source in both light and dark themes. Diagnostic metadata retains the full candidate build identifier.
- Use VLC's standard file icon for the video handler when VLC is available, with a dedicated video icon as fallback. Notify Windows Shell when the icon changes; existing Explorer views may need reopening.
- Preserve existing HDR game shortcuts, original game icons, launcher behavior and v1.2.4 reconnect/manual-override safeguards.

## Validation

- All 188 local automated tests passed: 131 Core and 57 Windows, with no exclusions or skips.
- The user accepted 1.3.0-local.1 with 17/17 manual checks: HDR10, SDR, original HDR ON, monitor reconnect, manual HDR override, cold launch and simultaneous game/VLC use on Windows 11 / Gigabyte MO34WQC2.
- The RC changes only version presentation, video handler icons and release preparation. Physical testing has not covered every format, GPU, display or reconnection scenario.
- GitHub Actions has not been run on this candidate: the development branch remains local at the user's request. A completely clean Windows VM is not available for validation on this host.

## Known limitations

- Windows 11 x64, an HDR-capable display and a compatible graphics driver are required. VLC must be installed or selected in settings.
- Video detection is conservative. Ambiguous or incomplete metadata does not enable HDR; Dolby Vision requires an explicitly compatible HDR10/HLG base layer.
- Controlled videos use a separate VLC instance. Keep the manager running in the tray during playback; unrelated VLC windows are not monitored or closed.
- HDR shortcuts can appear separately from running game windows on the Windows taskbar.
- Automatic keyless game-cover downloads are not included.

Before replacing a running portable build, exit the manager normally after games and controlled videos have finished. Open the new EXE from Explorer to refresh its existing stable launcher and video icon registration; existing HDR shortcuts retain their targets.

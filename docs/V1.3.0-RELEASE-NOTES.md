# Auto HDR Manager v1.3.0 — Smart Video HDR

This release adds automatic Windows HDR management for movies opened in VLC, alongside the existing game library and HDR shortcuts.

## New — Smart Video HDR

- Automatic HDR10 and HLG detection for MKV/MP4.
- Enable and confirm Windows HDR before VLC playback, with one second for display stabilization.
- Restore the original HDR state when the controlled VLC process closes.
- Independent VLC process monitoring, Explorer double-click activation and background cold start.
- Safe coordination between games and video playback through the existing shared HDR session.
- Bundled MediaInfo metadata detection and license notices: no separate FFmpeg or MediaInfo installation.
- Opt-in setup through Windows Default Apps; no direct UserChoice changes.

## Improvements

- Minimal v1.3.0 label in the main UI and About page.
- Familiar VLC MKV/MP4 icons, with a dedicated video icon when VLC is unavailable.
- English and Russian localization and matching, updated documentation.
- Stable 1.3.0 version metadata without local, rc or source-revision suffixes.

## Reliability

The display-reconnection safeguards introduced in v1.2.4 and the priority of manual HDR changes are preserved. Existing game-launch behavior, HDR shortcuts and IPC remain unchanged from the accepted implementation.

## Validation

- **188/188 local automated tests passed**: 131 Core + 57 Windows; no skips.
- **17/17 user acceptance checks passed** on Windows 11 / Gigabyte MO34WQC2, including HDR10, SDR, original HDR ON, monitor reconnect, manual HDR override, cold launch, simultaneous game/VLC use, file icons and version display.
- **HLG is covered by automated tests; physical HLG playback has not been confirmed.**

These checks do not establish compatibility with every monitor, GPU, driver, VLC version or hardware-reconnection scenario.

## Getting started

Install VLC, enable **Smart Video HDR** in Settings, click **Set up MKV/MP4 opening**, and choose **Auto HDR Manager Video** for the desired extensions in Windows Default Apps. Open movies normally and **fully close controlled VLC after viewing**. Keep the manager running in the tray.

## Known limitations

- Windows 11 x64 and an HDR-capable display/driver are required. VLC is installed separately.
- SDR and unknown metadata do not automatically enable HDR.
- Dolby Vision is not specifically supported. An explicitly compatible HDR10/HLG base layer may be used; Dolby Vision-only or ambiguous metadata does not enable HDR.
- Playback quality depends on VLC, the GPU/driver and display. Unrelated VLC processes are not monitored or closed.
- HDR shortcuts can appear separately from running game windows on the taskbar.
- Automatic keyless game-cover downloads are not included.
- The portable EXE is unsigned; verify SHA256SUMS.txt.

To update, finish games/videos, exit the old manager, replace the EXE and open the new copy once from Explorer. Existing settings and HDR shortcuts are retained. To return to direct VLC playback, choose VLC for MKV/MP4 in Windows Default Apps.

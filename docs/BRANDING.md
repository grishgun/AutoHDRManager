# Branding assets

The application logo is a cyan-to-magenta monitor with white HDR lettering and a gamepad, on a dark rounded tile. It was created with OpenAI image generation as a transparent, reference-guided reconstruction of the owner's approved design. It is not a vector extraction. No game artwork was used.

On 2026-11-04 the owner confirmed the rights to publish the supplied reference and the resulting logo and approved MIT for the project's original source and branding, copyright (c) 2026 grishgun. The root LICENSE covers these original assets; vendor assets keep their separate terms.

`src/AutoHDRManager.App/Assets/Logo.png` is the master. `scripts/build-icons.ps1` produces 16, 20, 24, 32, 48, 64, 128 and 256 px PNGs and a multi-resolution ICO. Installed game shortcuts use their own executable's icon locally; these game icons are not part of the repository.

Public screenshots are real 1.2.3 application windows using an isolated safe profile. Aurora, Orbit and Pulse are fictional demonstration entries with original geometric artwork made for this project. They are not actual bundled games. No third-party game cover art, user library data or reference presentation images are included.

Segoe UI and Segoe Fluent Icons are resolved from Windows, not redistributed as font files.
